# App Store listing assets

Generated 2026-08-24 alongside the app-icon replacement.

## There is nothing here to upload for the icon

Checked directly in App Store Connect on 2026-08-24 (app 1488594332): **App Information has
no app-icon field, and neither does the version page.** Apple takes the App Store icon from
the app binary's asset catalogue, so the listing icon changes when you ship a build — there
is no manual upload step, and no way to change it without submitting a version.

That means the icon work is already done by the repo: it lives in
`ios/Runner/Assets.xcassets/AppIcon.appiconset/` and is regenerated by
`dart run flutter_launcher_icons` (whose `remove_alpha_ios: true` strips the alpha channel
Apple rejects builds over). The next submitted build carries the new icon automatically.

`icon-1024.png` is kept here only as the marketing-size master — useful for a press kit,
the website, or anywhere outside the store that wants the artwork at full size. It is
1024 × 1024 RGB with no alpha.

## Regenerating

```
python tool/make_app_icon.py assets
dart run flutter_launcher_icons
```

then re-export `assets/appicon.png` at 1024 into this folder. It is already RGB, so no
alpha stripping is needed.

## Still to do by hand

**Screenshots.** The App Store requires iPhone screenshots, and the current listing's
predate the 1.14.0 interface refresh. They must come off an iPhone or the iOS simulator —
neither is available on this Windows machine, and an Android device cannot substitute, so
they are not captured here. Take them in **both** light and dark mode now that dark mode
renders correctly at the screen edges, covering at least: the map with coverage drawn, a
tower's detail sheet, and the legend.

**Submit a build.** As of 2026-08-24 the listing sits at **1.13.9** while the app is at
1.14.4, so several releases' worth of fixes — and the new icon — are not on the store yet.

**Privacy note for whoever takes the screenshots:** the app renders your live location,
your serving cell IDs and your carrier. Screenshots taken at home will publish your street
to the store listing. Capture somewhere neutral, or pick a view that does not centre on
where you live.
