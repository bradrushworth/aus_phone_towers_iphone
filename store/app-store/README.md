# App Store listing assets

Generated 2026-08-24 alongside the app-icon replacement. These are **not** uploaded
automatically — App Store Connect has no credentials in this repo. Upload under
**App Store Connect → your app → App Information**.

| File | Where it goes | Apple's requirement |
| --- | --- | --- |
| `icon-1024.png` | App Store icon | 1024 × 1024, **no alpha channel**, no rounded corners, no transparency. Apple applies the mask and rejects icons carrying alpha. |

The icon shipped inside the binary is separate and already handled: it lives in
`ios/Runner/Assets.xcassets/AppIcon.appiconset/` and is regenerated by
`dart run flutter_launcher_icons` (whose `remove_alpha_ios: true` strips alpha from the
iOS copies). This file is the same artwork at marketing size for the listing itself.

## Regenerating

```
python tool/make_app_icon.py assets
dart run flutter_launcher_icons
```

then re-export `assets/appicon.png` at 1024 into this folder. It is already RGB, so no
alpha stripping is needed.
